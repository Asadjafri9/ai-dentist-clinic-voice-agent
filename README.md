# AI Dentist Clinic Voice Agent

A focused starter project for an AI voice receptionist that helps dental clinics answer calls, qualify patients, and book appointments around the clock.

## Vision

- Answer common clinic questions with a friendly voice agent
- Capture new-patient details and treatment intent
- Route urgent requests to the right team member
- Connect callers with available appointment slots

## Run locally

This is a zero-dependency prototype. Open `index.html` directly in a browser, or serve the folder with any static web server:

```bash
npx serve .
```

## Next steps

1. Connect a realtime voice provider and speech-to-text pipeline.
2. Add clinic-specific knowledge and business hours.
3. Integrate scheduling and secure patient handoff.
4. Add consent, audit logging, and healthcare privacy controls before production use.
